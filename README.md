# Advent of Code 2025 Solutions

This repository contains code solutions to each of the 12 days of Advent of Code 2025.

My goal this year was to complete each problem using C++ and minimal libraries (where possible), and to document all of my solutions to create an additional learning resource for my master public [Notion page](https://quilted-eye-980.notion.site/Justin-s-LeetCode-Adventures-17ea88652aed4179a05be7baf027b886). You can find the AOC page of that Notion [here](https://quilted-eye-980.notion.site/AOC-2025-2be51433870b80e696d9fe7acf433e45). An additional motivation for me was to practice modern C++ language features such as lambdas and to stimulate my brain with some class design.

## Structure

The solutions are organized by day in the following format:

- `q01`, `q02`, ..., `q12`

Each subdirectory represents a different day of the challenge.

The vast majority of solutions are in C++, but I used Python for days which demanded SAT Solvers (I used Z3).
